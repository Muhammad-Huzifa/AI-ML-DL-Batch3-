# Notebook execution guide

Use each module's README to select the lesson. Start a fresh kernel when switching notebooks; they are separate classroom examples rather than one continuous application.

The Day 1 and Day 2 Python practice notebooks contain `TODO` placeholders, blank assignments, and incomplete formatted strings. Complete those cells before executing them. They are student worksheets, so a full run will raise syntax errors until the missing answers are supplied.

CSV references were corrected when a matching dataset was already committed. Open the notebook in Jupyter so its working directory is the notebook's directory. Image-training lessons still need their external datasets; inspect the existing Kaggle paths and attach the resources before training.

This organization pass also corrected a package-install cell, changed a keyword explanation to Markdown, and commented out two bare example image paths that were invalid Python. Generated outputs were cleared from the modified notebooks; model architectures and training settings were retained.

Notebook JSON and Python source were inspected. Every classroom task, framework installation, external dataset, and training run has not been executed in this environment.
