## Execution notes

Start in a fresh kernel and run setup cells first. Pandas debugging exercises, interactive Python demonstrations, unfinished worksheets, and external-data training notebooks are intentionally excluded from unattended CPU execution. Read each module dataset README before running its data-loading section. Generated outputs are written in the notebook working directory and ignored by Git.
