# Supplementary resources

## Bundled online reference

The [scikit-learn estimator map](../assets/references/scikit-learn-estimator-map.svg) was downloaded from the project's official source repository. It is preserved with its [BSD 3-Clause license and attribution](../assets/references/README.md). Other resources are linked to their publishers so students can access maintained examples without duplicating whole documentation sites in this repository.

The six new lesson PDFs are exports of this repository's existing PowerPoint files, rather than third-party slide decks. The [original outline](course-outline.pdf) and existing PDFs are retained.
