# Course map

[Course home](../README.md) · [Original course outline](course-outline.pdf)

The learning sequence below follows the material committed to this Batch 3 repository. The original NAVTTC outline is retained for reference; it also describes broader topics, including Linux and Azure, for which separate lesson materials are not currently included here.

| Stage | Module | Practice goal |
| --- | --- | --- |
| 1 | [Python](../modules/01-python/README.md) | Work with values, collections, functions, files, and classes |
| 2 | [NumPy](../modules/02-numpy/README.md) | Manipulate arrays and use vectorized operations |
| 3 | [Pandas](../modules/03-pandas/README.md) | Select, clean, summarize, and export tabular data |
| 4 | [Visualization](../modules/04-data-visualization/README.md) | Choose plots and explain patterns in a dataset |
| 5 | [Statistics](../modules/05-statistics-and-probability/README.md) | Describe center, spread, and probability |
| 6 | [Machine learning](../modules/06-machine-learning/README.md) | Fit regression/SVM examples and interpret evaluation results |
| 7 | [Deep learning](../modules/07-deep-learning/README.md) | Understand dense networks, regularization, and CNN architectures |
| 8 | [NLP](../modules/08-natural-language-processing/README.md) | Prepare review text and study an RNN sentiment classifier |

After Python OOP, complete the [ATM project](../projects/atm/README.md). Submit practice work in your own branch or fork using the [assignment sequence](../assignments/README.md). Read the instructor's assignment requirements before changing architectures or training settings.
