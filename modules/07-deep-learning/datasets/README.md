# Dataset notes

[Module home](../README.md) · [Course dataset guide](../../../docs/DATASETS.md)

MNIST and Fashion-MNIST are downloaded by TensorFlow/Keras when the notebook calls their dataset loaders. CNN classification lessons use external Kaggle image collections. Read the path, class names, preprocessing, and train/validation layout in the selected notebook before attaching data. Image datasets and learned weights are not committed to this repository.


Run the notebook's **Course data paths** setup cell before reading bundled inputs. Files created by saving/export exercises use the notebook working directory. Existing dataset provenance is retained as found; no unrecorded source or license is assigned to original course data.
